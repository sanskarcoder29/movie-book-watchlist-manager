# Movie & Book Watchlist Manager

A simple Python-based application designed to help users manage their personal collection of movies and books in one place.

## Project Overview

The Movie & Book Watchlist Manager allows users to add, view, search, update, delete, and organize their favourite movies and books.

The application also helps users track their watching and reading progress, maintain ratings, and view collection statistics.

## Planned Features

- Add movies and books.
- View all saved records.
- Search by title.
- Filter by genre and type.
- Update watching and reading status.
- Add and update personal ratings.
- Delete records.
- View top-rated entries.
- Track collection statistics.
- Save and load records using File Handling.

## Technologies Used

- Python

## Project Restrictions

- Based on Python concepts covered in Chapters 1–10.
- No Object-Oriented Programming.
- No external libraries or frameworks.
- Uses basic Python data structures and File Handling.
