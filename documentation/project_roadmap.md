\# Movie \& Book Watchlist Manager – Project Roadmap



\## 1. Project Overview



The Movie \& Book Watchlist Manager is a simple Python application designed to help users organize and manage their personal collection of movies and books.



Users will be able to add, view, search, update, delete, and organize their records in one place.



The application will also help users track their reading and watching progress, maintain ratings, and view collection statistics.



\## 2. Project Objectives



\- Build a useful application using basic Python concepts.

\- Understand how different Python data structures work together.

\- Practically apply the concepts covered in Chapters 1–10.

\- Develop a simple command-line application.

\- Learn teamwork and GitHub collaboration.



\## 3. Planned Features



1\. Add movies and books.

2\. View all saved records.

3\. Search records by title.

4\. Filter records by genre.

5\. Filter records by type.

6\. Update reading and watching status.

7\. Add and update personal ratings.

8\. Delete records.

9\. Display top-rated movies and books.

10\. View collection statistics.

11\. Save and load records using File I/O.



\## 4. Python Concepts Used



\- Variables and Input/Output

\- Conditional Statements

\- Loops

\- Strings

\- Lists

\- Dictionaries

\- Sets

\- Tuples

\- File Handling

\- Exception Handling



\## 5. Development Phases



\### Phase 1: Project Foundation



\- Understand the project requirements.

\- Create the basic dictionary structure.

\- Understand how movie and book records will be stored.

\- Test basic data operations.



\### Phase 2: Core Features



\- Develop the main menu.

\- Implement adding and viewing records.

\- Implement searching and deleting records.

\- Implement updating ratings and status.



\### Phase 3: Additional Features



\- Implement genre and type filtering.

\- Develop the top-rated collection.

\- Add collection statistics.

\- Implement permanent data storage using File I/O.



\### Phase 4: Testing and Integration



\- Combine all project modules.

\- Test the complete application.

\- Fix errors and improve the code.

\- Prepare for the final project evaluation.



\## 6. Project Restrictions



\- Only Python concepts covered in Chapters 1–10 will be used.

\- No Object-Oriented Programming.

\- No external Python libraries.

\- No databases or external APIs.

\- The application will use a command-line interface.



\## 7. Expected Outcome



The final outcome will be a working Python application that allows users to manage their movie and book collections while demonstrating the practical use of basic Python programming concepts.



The planned features may be improved or expanded based on team discussions and project requirements.
